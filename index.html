CXGX Studio

An internal upload tool for the YouTube channel “C&G Cooking” (しぃじーの本格お菓子作り)

Privacy Policy / プライバシーポリシー Terms of Service / 利用規約 C&G Cooking on YouTube

What it does

CXGX Studio is a small command-line tool used only by the team that runs the YouTube channel C&G Cooking (@cxgx_cooking). It uses the YouTube Data API to upload the team's own finished videos to the team's own channel as private videos, and to set their title, description, tags, thumbnail, captions and translated titles and descriptions.

  • Every upload is private. The tool has no function to publish, schedule, delete, or change the visibility of videos. A person on the team publishes each video manually in YouTube Studio.
  • Subscribers are not notified by the tool.
  • The tool is not offered to the public and does not access any other user's account or channel.

このツールについて

CXGX Studio は、YouTube チャンネル「しぃじーの本格お菓子作り（C&G Cooking）」の運営チームだけが使う、動画アップロード用のツールです。YouTube Data API を使って、自分たちが作った動画を自分たちのチャンネルに非公開でアップロードし、タイトル、概要欄、タグ、サムネイル、字幕、各言語のタイトルと概要欄を設定します。

  • アップロードは必ず非公開です。公開、予約公開、削除、公開範囲の変更の機能はなく、公開はチームの担当者が YouTube Studio で手作業で行います。
  • 登録者への通知は行いません。
  • 一般には提供しておらず、ほかの人のアカウントやチャンネルにはアクセスしません。
