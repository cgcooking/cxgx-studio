Privacy Policy

CXGX Studio — Last updated: 2026-11-10

HomeTerms of Service

CXGX Studio (“the tool”) is an internal tool used only by the team that runs the YouTube channel C&G Cooking (@cxgx_cooking) to upload its own videos to its own channel. The tool uses YouTube API Services. By using the tool, users agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Google user data the tool accesses

  • Basic information about the authorized YouTube channel (channel name, channel ID, handle, subscriber and video counts), to confirm that the tool is connected to the correct channel.
  • Videos, metadata (title, description, tags, category, language, translated titles and descriptions), thumbnails and caption tracks that the team itself uploads with the tool, and the processing status, privacy status and caption list of those videos.

OAuth scopes requested: https://www.googleapis.com/auth/youtube.upload and https://www.googleapis.com/auth/youtube.force-ssl.

How the data is used

The data is used only to upload the team's own videos as private videos, to set their metadata, thumbnails and captions, and to check that the upload succeeded. All values sent to YouTube are prepared by the team, each upload is started manually by the operator, and the tool prints a summary of what it sends. Videos are always uploaded as private; publishing is done manually in YouTube Studio.

How the data is stored

  • The OAuth token is stored only on the operator's own computer, in a file readable only by the operator. It is not uploaded anywhere else.
  • A local log on the operator's computer records the ID, file name, title and privacy status of each video uploaded by the tool.
  • The tool does not run on a server and does not store YouTube audiovisual content.

Sharing

The tool does not sell, share or transfer Google user data to any third party. The data is not used for advertising.

Revoking access and deleting data

Access can be revoked at any time on the Google security settings page: https://myaccount.google.com/permissions. On request, the stored token and local log are deleted within 7 days.

Limited Use

CXGX Studio's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
